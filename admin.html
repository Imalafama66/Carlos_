Cómo funciona

Edita cualquier sección desde el menú. Los cambios se guardan en este navegador usando localStorage. Usa la sección “Copias” para exportar/importar tus datos.

Importante: GitHub Pages no tiene base de datos. Para que tus cambios se vean automáticamente en todos los dispositivos necesitarás conectar un backend. Esta versión sí funciona sin servidor y no rompe la web.
