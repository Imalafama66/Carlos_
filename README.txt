xLAU — PORTAFOLIO DE CONFIGURACIÓN MINECRAFT

ARCHIVOS
- index.html: estructura y textos del sitio.
- style.css: diseño adaptable, efectos y animaciones.
- script.js: animaciones al aparecer, menú móvil y enlace de contacto.
- config.js: personalización rápida del enlace de contacto y año.

PARA PERSONALIZAR
1. Abre config.js.
2. En discordUrl, coloca tu enlace de Discord entre comillas.
   Ejemplo: discordUrl: "https://discord.gg/TUINVITACION",
3. Puedes editar los textos directamente en index.html.

PUBLICAR
- GitHub Pages: sube todos los archivos a un repositorio y activa Pages desde Settings.
- Netlify: arrastra la carpeta descomprimida al panel de despliegue manual.

NOTAS
- El sitio no necesita librerías JavaScript externas ni backend.
- Las fuentes web son opcionales; si no cargan, se usan fuentes alternativas.
- El diseño usa animaciones CSS ligeras y IntersectionObserver para revelar secciones.
- Las tarjetas de proyectos muestran categorías de servicio de ejemplo, no clientes confirmados.
- El botón de contacto usa un correo genérico hasta que agregues tu enlace en config.js.
- "Sin lag" absoluto no se puede garantizar en todos los dispositivos o redes; el sitio está diseñado para ser ligero y adaptable.
