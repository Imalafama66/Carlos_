## Sobre Mí 🚀

Soy desarrollador Backend apasionado por la tecnología y la creación de soluciones eficientes, escalables y de alto rendimiento. Especializado en desarrollo Java, arquitectura de servidores y optimización de sistemas Linux.

Mi objetivo es combinar lógica, buenas prácticas y rendimiento para construir productos robustos, desde APIs backend hasta infraestructura de redes complejas.
