# IMALAFAMA66 STUDIO — tienda profesional

Tienda/portfolio en blanco y negro con diseño premium, animaciones visuales, filtros por categoría y panel de edición separado.

## Categorías incluidas
LOGOS · BANNERS · DISEÑOS · WEBS · BRANDING · REDES

## Puedes editar
- Nombre, descripción y contacto.
- Todos los servicios y precios.
- Categorías e imágenes/URLs.
- Todos los logos, banners y trabajos del portfolio.
- Estados COMPLETADO / AVANZANDO / PRÓXIMAMENTE.
- Reseñas.
- Ventas/pedidos.
- Estadísticas.
- Textos.
- Importar/exportar configuración JSON.

## Importante
La edición usa localStorage. En GitHub Pages los cambios se guardan en el navegador donde los haces; no se sincronizan automáticamente con todos los visitantes. Para sincronización global se necesita una base de datos/backend.
